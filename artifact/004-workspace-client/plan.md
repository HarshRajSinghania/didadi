# React 工作区客户端

依赖 draft PR #6（其依赖 #5），独立 worktree/分支。不合并，不公网部署，不配置账户安全或外部凭据。既有 8765/8766 与数据保留，客户端用 8767；复用 8009/9001 真实后端和 Git 文档。

目标：React + matrix-js-sdk 同一界面选择真实已加入/本地测试房间、发送消息/明确提及回显示例 Agent、看真实回复/任务状态、编辑共享 demo.md、查看不可变历史与显式冲突。标注非 LLM。

适配层：loopback-only Python server，SDK 通过受限 Matrix 路由代理使用已有本地测试身份；浏览器只拿短期 CSRF，不拿 Matrix/AS/worker token。服务器限定允许房间、路径、HTTP 方法、内容与无加密/agent 成员检查；Git 仍是文档权威。外部文档 worker 复用 8766 演示，避免混用 echo runtime。创建房间仅生成隔离非管理员测试用户的私有本机房间，重复请求用确定性别名恢复。

回归：真实浏览器选择/创建房间、消息与示例回复、Git 保存/读回、历史版本与旧版本冲突、重复点击/稳定 Matrix txn、后端失败保留输入/可重试。组件测试覆盖正常/失败/重复状态；Python 测试代理权限边界/重复与失败；构建 + 全量已有测试 + 真实 Matrix/document CI。最终 CI 对应最终 SHA。

边界：本地测试会话，无生产登录/多租户 grants、E2EE、真实模型、公网或远端凭据；共享 demo.md 不是每房间独立资源授权实现。
